## 🚀 Tasks Overview
The project includes 9 different tasks covering fundamental and advanced Python concepts:

1.  **Phonebook Manager:** A system to add, search, and delete contacts using dictionaries.
2.  **Student Exam Scores:** Calculates average scores using dictionary comprehension.
3.  **Find Maximum in Matrix:** Searches 2D lists for the highest value and its position.
4.  **Transpose of Matrix:** Matrix manipulation by swapping rows and columns.
5.  **Remove Duplicates:** Cleans lists while preserving the original order.
6.  **Factorial & Combinations:** Implements recursion for mathematical calculations.
7.  **Banking System:** Simulates account creation, deposits, and withdrawals with validation.
8.  **Event Ticket Booking:** A full booking system with early bird and group discounts.
9.  **Restaurant Order System:** A POS simulation with taxes, service charges, and senior discounts.
